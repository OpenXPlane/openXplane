# Contributing to openXplane

Thanks for helping! A few rules keep the project healthy:

- **No original code or assets.** Never copy anything from an X-Plane installation into the repository: no
  textures, models, sounds, airfoils, aircraft or scenery, and no code or disassembly listings. Tests that need
  content read it from a local installation in `Xplane12/` and skip themselves without one. Research notes
  describe behaviour in our own words with addresses and constants as evidence.
- **Confirm, do not guess.** A rule is implemented as the original's only after it has been confirmed in the
  reference build; what is assumed is labelled as such (see `research/FLIGHT_MODEL.md`). New ports are verified
  against the original machine code in the emulator (`research/VERIFICATION.md`).
- **One change per pull request**, with a message that says what changes for the user.
- `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings` and
  `cargo test --workspace` must pass (CI runs them on Linux, macOS and Windows).
- Code style: `rustfmt` defaults; comments explain *why*. Public text (docs, site, commit messages) is English.

## Files and licences

- Contributions are MIT, like the rest of the repository.
- No large files: a file of a megabyte or more is rejected. Test vectors are small and generated by the tools in
  `tools/` from synthetic inputs.
- No generated or downloaded content (builds, caches, converted assets, original data).
