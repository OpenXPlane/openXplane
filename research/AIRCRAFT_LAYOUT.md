# Aircraft object layout (from the datarefs)

The aircraft object (returned by the singleton getter `0x141a64260`, the one at `F+0x20` of the flight object) holds
the aircraft parameters at fixed offsets. The scalar `sim/aircraft/...` datarefs read them, so their getters name
the offsets. The table is produced by `tools/extract_aircraft_layout.py` from the dataref catalog and the
executable; an offset with two names is read by two datarefs (an alias or a union). Array datarefs are not listed.

Offsets used by the ported engine and element force code (research/ENGINE.md, research/WING_ELEMENT.md) with
what the table says about them: `+0x91c` number of engines, `+0x950` jet face area, `+0x984` maximum Mach
efficiency (the critical Mach number of the intake), `+0x9d4` minimum N2 governor, `+0xa24` jet fuel intro time,
`+0xa2c` turbine spool time, `+0xb38..+0xb68` the jet cruise, climb and take-off tables (N1, Mach, fuel flow ratio),
`+0xc18` starter torque ratio, `+0xc1c` starter maximum rpm ratio, `+0x1a74..+0x1aa4` ITT and EGT limits,
`+0x1eb0` flap detents, `+0x1f00` slat increment, `+0x1f04` and `+0x1f40` slat drag, `+0x1f74` flap type,
`+0x1f78..+0x1f80` and `+0x1fb8..+0x1fc0` flap lift, drag and moment coefficients.
