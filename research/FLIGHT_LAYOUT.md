# Flight object layout (from the datarefs)

The flight object (`F` in the research notes: the object the singleton getter `0x141a64250` returns for the
flight model) holds the simulation state. The scalar `sim/flightmodel`, `sim/weather` and `sim/operation`
datarefs read it, so their getters name offsets. The same getter returns other objects for other tables, so an
offset can also carry names of other groups; only the groups above are listed here (all of the table is made by
the method of `tools/extract_aircraft_layout.py`, with the singleton `0x141a64250`).

Offsets used by the ported code (research/ENGINE.md, research/WING_ELEMENT.md): `+0x6c` air density `rho`,
`+0x70` density ratio `sigma`, `+0x400` true airspeed, `+0x41c` equivalent airspeed, `+0x420` Mach number,
`+0x424` the static dynamic-pressure term `Qstatic`, `+0x408` sideslip angle `beta`, `+0x3cc/+0x3d0/+0x3d4` the
body rates P, Q and R (degrees per second), `+0x368..+0x370` the velocity `local_vx/vy/vz`, `+0x24c`
`onground_any`, `+0x6880` the fuel-flow override.
